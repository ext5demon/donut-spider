Development-package artwork supplied by the project owner.

- `source.png`: the supplied logo, preserved byte for byte.
- `ICON0.PNG`: 320 x 176 RGBA icon; the complete square logo is centered with transparent side margins.
- `PIC1.PNG`: 1920 x 1080 RGB XMB background; the complete logo is enlarged by an integer factor and centered on black.

`tools/build-bdev05.sh` packages the icon and background. The public package keeps separate copies of the same XMB artwork. The in-game chapter picker is separate.
