# Spider Donut bdev05

This development build addresses the Chapter 4 window dust and Sanctuary pulse reports. The missing `shd_ripple` implementation made the game's pulse rectangles visible as solid boxes. The renderer now accepts its center and radius uniforms and shades the rectangles into fading circular bands on PS3. The same fix covers footstep pulses and the music pulses at the second Sanctuary opening.

Window dust was generated by the game but lost when drawing its intermediate surface: the legacy renderer's tiled-surface operation was empty. That operation now repeats the surface with its requested offset, scale, tint and alpha. It uses one repeating quad rather than a draw for every tile.

The PS3 clock also returned truncated seconds where the runner expected nanoseconds. This build restores sub-millisecond time and the units expected by GML `current_time` and `get_timer`, including after long console uptime. This is a confirmed timing bug; it has not been established as the cause of the reported battle pauses.

The fixed-function fragment program now retains unchanged texture/fog constants between draws. This removes redundant command-buffer transfers, while preserving every program binding, matrix upload and hardware draw-state submission needed by startup and surface transitions. A recorder verifies 1,000 repeated draws without additional constant transfers and verifies changes to fog state. Physical PS3 frame-rate gains remain unmeasured.

The prophecy-glass, battle-start, recruiting, Mizzle, Balthizard and Gerson performance reports still require console retesting. No encounter has been skipped or its effects disabled. Completed step, audio, draw, swap and room-transition phases taking at least 250 ms now leave a `SLOW PHASE` record in the session log, so brief pauses can be distinguished from the existing ten-second hang watchdog. Normal frame pacing is excluded.

Validation:

- 29 host regressions, plus the same suite under AddressSanitizer and UndefinedBehaviorSanitizer.
- Real OpenGL pixel checks for circular fading pulses and tiled surfaces, including mirrored offsets and alpha.
- Before/after native fixtures running the owned Chapter 4 scripts: solid pulse boxes become rings, and previously absent window dust appears. These are isolated fixtures, not a full playthrough or a PS3 emulator test.
- PS3 cross-build, package metadata/footer, exact source archive, private-file and secret audit.

Install `spider-donut-bdev05.pkg` over the existing installation. Title ID remains `DONSD0001`; installer revision is `00.19`. Keep existing chapter data, texture bundles, videos and saves. The dev7.1/v0.1 preloader artwork, layout, animations and controls are unchanged. No chapter files or texture bundles are included or regenerated. The public v0.2 release remains unchanged.

Retest both Sanctuary pulse scenes, window dust, prophecy glass breaks, recruitment, Mizzle/Balthizard attacks and Gerson's parry. If a pause remains, the session log is in `/dev_hdd0/game/DONSD0001/USRDIR/logs/`. Earlier Chapter 3 changes and Knight diagnostic records are retained; this build does not claim to resolve the Knight's reported post-defeat disappearance.
