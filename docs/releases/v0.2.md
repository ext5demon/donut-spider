# Spider Donut v0.2 Beta

Chapter 3 is now listed as **fully playable**, based on the project's playtesting. This release contains the current Chapter 3 runner through bdev04. Fully playable means a chapter can be played through; known bugs can remain.

| Chapter | Status |
| --- | --- |
| Chapter 1 | Fully playable |
| Chapter 2 | Playable with some minor bugs |
| Chapter 3 | Fully playable |
| Chapter 4 | Bootable |
| Chapter 5 | Doesn't work |

Changes since v0.1 include the Chapter 3 desert-pit motion-grid fix, additional drawing effects used by Tenna and the Knight, audio-state corrections, destination-alpha masking fixes for the Knight's attacks, and reduced repeated palette/fog uploads on PS3. Video playback is enabled in the release build; prepare the required BSV video and Ogg audio sidecars using the README instructions.

The preloader artwork, layout, animation, sounds and controls are unchanged from dev7.1/v0.1. This release makes no new gameplay or preloader changes beyond the existing bdev04 code.

Known Chapter 3 reports remain open: slowdowns in the Knight's full-screen explosive-spike attack and missing sprites after defeating him. bdev04 reduced redundant drawing work and added `KNIGHT STATE` / `KNIGHT DESTROY` logging; it did not establish a console fix for the post-defeat issue. Some demanding scenes can still stutter. Chapter 4 development belongs to the next development build and is not included here.

Install **spider-donut-v0.2.pkg** with the PS3 Package Manager on HEN/CFW. Install over the existing app and keep chapter files and saves. Title ID stays **DONSD0001**; installer revision **00.18** is separate from the public version **v0.2**.

You supply your own matching `data.win`, PS3 `TEXTURES.BIN`, audio and converted videos. No chapter data, gameplay texture bundles, music, videos or saves are distributed. The README covers conversion, folder layout, controls, logs and source builds.

The release is checked with 28 normal and 28 ASAN/UBSAN host regressions, PS3 cross-compilation, package/source inspection and secret scans. These checks do not replace a physical PS3 playthrough. The source ZIP matches the tagged release commit; checksums and a verification report accompany the PKG.
