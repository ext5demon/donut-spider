# Spider Donut v0.1 Beta

The first public beta brings the development runner through dev7.2 into a
source release and PS3 installer. Your own matching game files are required.

| Chapter | Status |
| --- | --- |
| 1 | Fully playable |
| 2 | Playable with some minor bugs |
| 3 | Doesn't work |
| 4 | Bootable |
| 5 | Doesn't work |

The runner includes mounted-storage chapter discovery and manual browsing,
controller handoff/reconnection fixes, diagonal collision and battle-surface
corrections, bounded GPU readback submission, fractional sprite/background parts,
palette/hue/grayscale compatibility, offscreen quad culling and audio cut/restart
smoothing. Draw-state submission follows the dev7.2 compatibility path.

The public animated launcher uses original icons, cursor and synthesized cues,
plus the existing openly licensed JetBrains Mono debug font. Extracted game menu
artwork and recordings from private development builds are not distributed.

Install `spider-donut-v0.1.pkg` with Package Manager. Keep existing chapter folders
and matching PS3 `TEXTURES.BIN` bundles. The README includes per-chapter conversion,
USB/internal layouts, controls, logging and source-build instructions.

The application title ID remains DONSD0001 to preserve dev6/dev7 saves and logs.
Installer revision 00.12 is an upgrade counter; the public version/tag is v0.1.
Back up saves before upgrading, then install over the existing development app.

Beta limits remain: demanding scenes can slow down or stutter, some GML/shader
features are incomplete, and the chapter status table applies. Enemy-dialogue
clipping and the Lancer Key Item highlight discrepancy remain open PS3 QA items.
The public package's new launcher assets still need real-console confirmation.

The release is checked with 26 host regressions in normal and ASAN/UBSAN builds,
plus PS3 package/source inspection and a secret scan. Host checks do not replace
real-console gameplay tests. See the included release verification for results.
