# Spider Donut v0.3 Beta

This release publishes the current runner through bdev06 and updates the README's chapter status: **Chapter 3 is fully playable; Chapter 4 is playable.** Statuses reflect project playtesting and do not mean every bug has been resolved.

| Chapter | Status |
| --- | --- |
| Chapter 1 | Fully playable |
| Chapter 2 | Playable with some minor bugs |
| Chapter 3 | Fully playable |
| Chapter 4 | Playable |
| Chapter 5 | Doesn't work |

Changes since v0.2:

- Chapter 4 Sanctuary pulses use circular masks and the authored Bezier growth/fade curves.
- Church window dust survives its intermediate tiled-surface drawing pass.
- Crystal-tower sprites remain visible when scripts move them onto runtime-created layers. Same-layer and invalid layer moves are handled safely.
- The PS3 game clock returns nanoseconds with the precision expected by GML time functions.
- Unchanged fixed-function shader constants are retained between draws; pulse drawing uses a smaller dedicated PS3 shader.
- Session logs include completed slow phases and GPU wait/draw/vertex counts to help diagnose brief pauses and GPU stalls.
- The supplied Spider Donut logo is included as the XMB icon and background.

Game, renderer and preloader source match bdev06. The dev7.1/v0.1 preloader artwork, layout, animations, sounds and controls have not been redesigned for this release.

## Known issues

The Chapter 4 Titan Spawn progressive GPU slowdown/exit, Wicabel/Organikk encounter performance and black-flame tower chase still require console confirmation. The bdev06 changes do **not** establish that the Spawn crash is fixed. A separately reported old-picker screen remains undiagnosed. Earlier Chapter 3 reports concerning the Knight's full-screen attack slowdown and missing post-defeat sprites remain open. Demanding scenes can stutter; host regressions do not replace PS3 playtesting.

## Install

Download **spider-donut-v0.3.pkg** from the assets attached to this release and install it with the PS3 Package Manager on HEN/CFW. Install over the existing app and retain chapter files, videos and saves. Title ID stays **DONSD0001**; PS3 installer revision **00.22** is independent of the public version **v0.3**.

Supply your own matching `data.win`, PS3 `TEXTURES.BIN`, loose audio and converted videos. No chapter WADs, gameplay texture bundles, music, videos, saves, tester logs or private fixtures are distributed. The README includes converter commands, chapter-folder layout, controls, logging and source-build instructions.

Validation includes 30 normal and 30 ASAN/UBSAN host regressions, PS3 cross-compilation, shader/package/source inspection, and private-file/secret scans. The source ZIP matches the tagged commit. A verification report and SHA-256 checksums accompany the PKG.
